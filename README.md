# Estudo independente do The News com REA

Relatório, capturas, mapa de rotas e protótipo fictício para leitura em celular. Coleta em 15/10/2026.

A aplicação estática está em dist/index.html e não exige instalação, autenticação ou backend. As evidências originais estão no pacote técnico opcional.

Não é um site oficial do The News. O protótipo não envia e-mails nem cria inscrições. Marca e capturas do site analisado pertencem aos respectivos titulares; os textos e componentes da demonstração café breve foram criados para este estudo.
